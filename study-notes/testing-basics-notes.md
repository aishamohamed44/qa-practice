## 1. What is software testing?

- Testing means checking that software works the way it should.
- We look for problems (bugs) before real users find them.
- Testing is not only "finding bugs" - it also gives the team information about quality.

## 2. Manual testing basics (in progress)

- **Test case:** a set of steps + expected result, so anyone can repeat the test.
- **Positive testing:** check the system works with correct input.
- **Negative testing:** check the system handles wrong input in a safe way.
- **Regression testing:** after a change, test again what worked before.

## 3. Writing a bug report (in progress)

A good bug report has:
- Short, clear title
- Environment (browser, device, OS)
- Steps to reproduce
- Actual result vs expected result
- Severity or priority
